## anime-face-detector (anime face detector and landmark model)

Arils can bundle Core ML exports of the anime face detector (Faster R-CNN
R50-FPN) and the 28-point landmark model (HRNetV2-W18) from
hysts/anime-face-detector, generated by
`Arils/Tools/AnimeFaceModels/export_coreml.py` into
`Arils/Sources/ArilsFaceInference/Resources/AnimeFaceModels`. The NMS, RoIAlign
and heatmap-decoding steps in `ArilsFaceInference` are ports of the package's
inference code.

- Project: hysts/anime-face-detector (<https://github.com/hysts/anime-face-detector>),
  MIT License, Copyright (c) 2021 hysts; the vendored mmdetection/mmpose parts
  it ports are Apache License 2.0 (OpenMMLab)
- Weights: <https://huggingface.co/hysts/anime-face-detector-faster-rcnn> and
  <https://huggingface.co/hysts/anime-face-detector-hrnetv2>, MIT License
- `scripts/anime_face_server.py` runs the same models from Python for
  development comparisons; the app does not use it

## anime-segmentation (anime character segmentation model)

Arils can bundle a Core ML export of the ISNet character segmentation model
from SkyTNT/anime-segmentation, generated by
`Arils/Tools/AnimeSegmentationModel/export_coreml.py` into
`Arils/Sources/ArilsSubjectInference/Resources/AnimeSegmentationModel`. The
export script downloads the network definition and the weights at pinned
revisions; neither is committed. The letterbox preprocessing in
`ArilsSubjectInference` follows the project's `inference.py`.

- Project: SkyTNT/anime-segmentation (<https://github.com/SkyTNT/anime-segmentation>),
  Apache License 2.0; its ISNet definition is borrowed from xuebinqin/DIS
- Weights: <https://huggingface.co/skytnt/anime-seg> (`model.safetensors`),
  Apache License 2.0

Mac

macOS 26.5 以降・Apple シリコン（M1 以降）

Mac 版をダウンロード
  1. ダウンロードした .dmg を開き、Castor を「アプリケーション」へドラッグ
  2. 最初の起動だけ、「システム設定 › プライバシーとセキュリティ › このまま開く」で許可
  3. Castor が開いたら、絵を1枚入れる
最初の起動の手順を動画で見る
Windows

Windows 10 / 11（64 ビット）

Windows 版をダウンロード
  1. ダウンロードした zip を展開し、CastorSetup.exe を開く
  2. 「Windows によって PC が保護されました」と出たら「詳細情報 › 実行」
  3. セットアップの案内に沿ってインストールし、Castor を起動

Windows 版は公開プレビューです。

Castor はパソコン用のアプリです。Mac か Windows のパソコンで開いてください。

Release に並んでいるファイルの見分け方

ふつうは上のボタンだけで足ります。GitHub の Release ページには、用途ごとに次のファイルが並んでいます。

ファイル用途
更新・削除・署名について
  • 更新・修復・削除は、セットアップ（Mac は Castor の設定から開けます）でいつでもできます。作ったペットと設定は残ります。
  • いまは Apple・Microsoft の公式署名がないため、最初の起動で OS の確認画面が出ます。ダウンロード内容は配布元の一覧（SHA-256）と照合しています。
  • うまくいかないときは GitHub の Issues で教えてください。

安心して使えるように

  • 無料・オープンソースソースコードはすべて GitHub で公開しています（MIT ライセンス）。
  • 絵は外に送りません切り抜きと顔の推定は、この端末の中で処理します。
  • 会話は選べます手元の AI でも、Codex / Claude Code でも。外部に送るときは毎回確認します。

よくある質問

どんな絵でも動きますか？

正面向きで、顔がはっきりした絵が一番きれいに動きます。崩れたときは、顔の目印を手で直せます。

お金はかかりますか？

かかりません。外部の AI サービスを選んだ場合だけ、そのサービスの料金がかかります。

使う絵の注意は？

自分で描いた絵か、使ってよい絵でお願いします。

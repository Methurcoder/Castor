# カーソル光の粒子の波（2026-10-20）

ユーザーの要望: 滑らかな動きのまま、小さな粒子が集まって波を描く背景をCastorへ導入する。

- ドットをコマ送りやピクセルの段階移動にせず、位置を連続的に動かす。
- 196粒を単一Canvasの8パスにまとめ、粒ごとのSwiftUI Viewやぼかしを作らない。
- カーソルの動きに反応して波打ち、静止後は減衰して描画更新を止める。
- macOSの視差効果を減らす設定を尊重し、背景が操作を遮らない。
- 変形計算の重複削減とカーソル通知の背景への分離も一緒に組み込む。
- Claudeの最新の顔推定・Windowsマーカー修正を保持する。公開Releaseは今回行わない。

実装: `Castor/Castor/Visual Language/CastorDesign.swift` と `ContentView.swift`。

# ペット退避(Evasion)ロードマップ — 場所を譲る・性格で譲り方が変わる

2026-07-14 時点の構想。フローティングペットが、ユーザーが使いたい画面領域を
**即座に・キャラクターらしく**譲り、用が済んだら元の場所へ帰る機能の計画書。

## 実装状況(2026-07-14)

- M1〜M4を実装済み。実装本体は `pomegranate/pomegranate/Pet/PetEvasion.swift`、
  パネル統合は `PomegranatePetController.swift`、演技統合は `MotionContext` /
  `CherryConnection`、設定と永続化は `VoiceSelectionView` / `PetCharacterStore` に置く。
- 仮値だった重なり20%または中心被覆、帰巣8秒、クールダウン15秒、手動配置保護5分、
  読み込みキャラ既定calm、同一ディスプレイ内完結をv1の確定値として採用した。
- M5(ScreenCaptureKit、切迫度エスカレーション、ディスプレイ間移動の最適化)は将来枠のまま。
- 画面収録権限は追加していない。Ollama分類はpersonality保存時だけで、退避時には呼ばない。
- 初期実装の「前面ウインドウと重なれば即退避」は、最大化ウインドウで常時ゴースト化するため廃止。
  現在は前面ウインドウとの重なりに加えて、カーソルがペット枠の外周52ptへ近づいた場合だけ
  「その場所を使いたい」と判定する。カーソルがペット枠内へ入った場合はペット操作を優先する。
  最大化ウインドウ自体は移動先の障害物から除き、カーソルから離れた画面端へ退避できる。
- General Settings の `Pet Evasion · BETA` からオン・オフ可能。既定値はオフ。

## 目的と前提(先に要点)

- **体感即時**: ユーザーが「その場所を使いたい」と分かってから退避開始まで最悪1秒以内。
  2秒待たされる時点で不快、が出発点。
- **権限最小・ローカル優先**(Pomeの既存原則): v1 は**画面収録権限を要求しない**。
  「周囲の色を監視して変化したらスクリーンショット解析」案は、
  小領域のピクセル取得でも全画面スクリーンショットと同じ画面収録権限(TCC)が必要なため不採用。
  代わりに `CGWindowListCopyWindowInfo` の**ウインドウ矩形メタデータ**
  (権限プロンプト無し・数十µs/回)で「邪魔かどうか」を厳密に判定する。
- **省エネ**: イベント駆動+低頻度ポーリングの二段構え。重い処理は存在自体をオプトインの将来枠へ。
- **推定は実行時にしない**: 退避スタイルの決定は事前(宣言的)。退避の瞬間にLLM等は呼ばない。
- **性格はデータ、ステートマシンは1つ**: スタイル差は if 分岐ではなく `EvasionProfile` の
  パラメータ差で表現する(モーション語彙 `MotionParameters` に意味判定を持ち込まない既存流儀)。

## 非目標(v1ではやらない)

- 画面収録権限が要る一切(ウインドウ内の余白検出、デスクトップアイコン回避、動画プレイヤーのHUD回避)
- 退避時のLLM推論・クラウド接続
- ウインドウを「押しのける」等の他アプリ操作

## アーキテクチャ

### 検知(3層)

```
第1層(プッシュ・常時) : NSWorkspace アプリ切替通知 / ペットへのホバー・ドラッグ(既存)
第2層(1〜2Hzポーリング): CGWindowListCopyWindowInfo → 前面ウインドウ矩形とペット枠の交差判定
第3層(将来・オプトイン): ScreenCaptureKit によるピクセル解析(画面収録権限を明示的に取った人のみ)
```

- 「邪魔」の定義(v1): **フォーカスの当たったウインドウ**(またはその直近操作対象)と
  ペットパネルの矩形が閾値以上重なり、かつカーソルがペット枠の外周へ近づいたこと。
  単なる重なり、非アクティブウインドウとの重なり、ペット自身へのホバーは許容する。
- 行き先: 前面ウインドウ群の補集合から**空き矩形**を計算し、現在地から最寄りの候補を選ぶ。
  ピクセル不要・純ロジックでテスト可能。
- 空きが無い場合のフォールバック: **ゴースト化**(アルファ約0.15+クリック透過)。
  フルスクリーンアプリがアクティブな間は非表示。

### 退避ステートマシン(1つだけ)

```
settled(home) ─重なり検知─► anticipating(スタイルの「ため」) ─► evading(移動)
     ▲                                                        │
     └─ returning(帰巣) ◄─ 占有解消がN秒継続+クールダウン ◄─ displaced(退避先で待機)
```

- **home座標の記憶**: ユーザーが最後に手で置いた位置=home。帰巣先は常にここ。
- **ヒステリシス必須**: 重なり判定・解消判定の両方に猶予時間(ウインドウ端のジッタで
  往復ビンタしない)。退避→帰巣→退避の最短周期にクールダウンを設ける。
- **手動配置は聖域**: ユーザーがドラッグ配置した直後(既定5分)は自動退避しない。
  「どかしたのにまた来た」を絶対に起こさない。
- **会話継続**: 発話・listening中に退避しても音声パイプラインは中断しない。
- 責務分離: パネル座標の移動は `PomegranatePetController`、
  身振り・視線・声は `MotionContext`/`CherryConnection` 経由(移動と演技を別レイヤーに保つ)。

### 退避スタイル(性格×退避)

```swift
enum EvasionStyle: String, Codable, CaseIterable { case cute, calm, cool, proud, robot }

struct EvasionProfile {
    var anticipationDelay: TimeInterval   // 気づいてから動き出すまでの「ため」
    var pathEasing: ...                   // バネ跳ね / 滑らか / 等速スライド
    var bodyCue: ...                      // 跳ね / 会釈 / なし / 不満顔
    var gazeCue: ...                      // 相手ウインドウ方向を見るか
    var voiceLine: String?                // nil = 無言
    var soundEffect: ...?                 // robot の機械音など
    var returnManner: ...                 // 帰り方(そっと / 堂々と / 瞬間移動)
}
```

| スタイル | 演技 | 実装に使う既存プリミティブ |
|---|---|---|
| cute  | びくっと跳ねて「わっ、ごめん!」 | 減衰不足バネのホップ+`touchSquash`系の潰れ+TTS一言(口パク既存経路) |
| calm  | 一歩下がって軽く会釈 | `angleY`を一瞬下げる+ゆっくりイージング、無言か小声 |
| cool  | 無言で視線だけ向けて退く | `externalGazeTarget`に相手ウインドウ座標を渡す+等速移動+声なし |
| proud | 少し不満そうにゆっくり移動 | `anticipationDelay`長め+`mouthForm`/眉で不満顔+過減衰移動 |
| robot | 機械音+スライド退避 | ため0+等速スライド+`energy`低下で揺らぎ抑制+SE |

- **スタイルの決定**(推定は初期値の提案まで、確定は宣言的に):
  - 公式4キャラ: 固定割り当て(コードに手書き。共通設定で上書きしない — AGENTS.md 原則6)
  - 読み込みキャラ: 性格文の**保存時に1回だけ** Ollama で5択分類してプリセット
    (失敗時・未接続時は既定値)。`VoiceSelectionView` に Picker を置き**ユーザーが常に上書き可能**。
    確定値は `PetCharacterStore` に永続化。
- **セリフ頻度制限**: 毎回は喋らない(セッション初回のみ、または確率20%程度)。
- **エスカレーション**(任意・後回し可): 同じウインドウに短時間で繰り返し追われたら、
  スタイルに関わらず段階的に慌てる(スタイル×切迫度の2軸)。「不器用な生命感」テーマと整合。

## マイルストーン

| # | 内容 | 規模 | 依存 |
|---|---|---|---|
| M1 | 検知層: ウインドウ矩形取得ラッパ+交差判定・空き矩形計算・ヒステリシスの純ロジック | 中 | なし |
| M2 | 退避ステートマシン+`PomegranatePetController` のパネル移動・home記憶・帰巣 | 中 | M1 |
| M3 | `EvasionStyle`/`EvasionProfile` と演技(身振り・視線・声・SE)の接続 | 中 | M2 |
| M4 | スタイル決定: 公式キャラ固定表+性格保存時のOllama一括分類+設定UI(Picker) | 小 | M3 |
| M5 | (将来枠)第3層ピクセル解析のオプトイン、エスカレーション、マルチディスプレイ最適化 | 大 | M2 |

### 受け入れ基準

- **M1**: 交差判定・空き矩形選択・ヒステリシスが実ウインドウ無しの合成入力でテストできる
  (純ロジック。既存原則「テスト可能な純粋ロジックを残す」)。
  CPU負荷: ポーリング1周期あたり実測1ms未満。
- **M2**: フォーカスウインドウをペットに重ねると1秒以内に退避開始。
  ウインドウを閉じるとN秒後にhomeへ帰る。手動ドラッグ直後は追跡しない。
  ウインドウ端で小刻みに揺らしても往復しない。
- **M3**: 5スタイルが同一ステートマシンで動き、スタイル追加が `EvasionProfile` 定義の
  追加だけで済む。発話中に退避しても読み上げが途切れない。
- **M4**: Ollama未起動でも既定スタイルで全機能が動く(フォールバック原則)。
  公式キャラのスタイルは設定UIから変更できない。

## テスト方針

- 判定・選択・ヒステリシス・プロファイル解決は全て純ロジックとして
  `pomegranateTests` へ(実ウインドウ・実パネル不要)。
- `CGWindowListCopyWindowInfo` は薄いprotocolで包み、テストでは合成ウインドウリストを注入。
- 演技は既存の `MotionParameters` 決定論テストの流儀(同一入力→同一出力)に従う。

## 決めておくこと(実装開始時に確認)

1. 「邪魔」閾値: 重なり面積比か、ペット中心点の被覆か(推奨: 面積比20%+中心点被覆のOR)
2. 帰巣までの猶予N秒(仮: 8秒)とクールダウン(仮: 15秒)
3. 手動配置の聖域時間(仮: 5分)と、聖域中に重なった場合の挙動(仮: ゴースト化のみ許可)
4. 読み込みキャラの既定スタイル(仮: calm — 最も事故が少ない)
5. マルチディスプレイ: v1は「ペットがいるディスプレイ内」だけで完結させるか(推奨: する)

# Castor v1.0.1

macOSの「GIFを作ってXで共有」がタイトルバーだけになる問題への修正版です。

- SwiftUIのサイズ計測とウインドウのサイズ管理を分離しました。
- 初期表示490×650、最小490×600をウインドウ側で維持し、リサイズに追従します。
- 開き直し時の古い終了通知が新しい画面を消さないようにしました。

Windows本体、セットアップ、Neural TTSのコード変更はありません。
これらの配布物はv1.0.0と同じバイナリを使用します。
Mac本体はv1.0.1（build 5）として再ビルドします。

## 確認範囲

ビルドと配布物検査の結果は公開前に追記します。
追加テスト、修正後の実機GUIでのGIF作成・保存・X共有は未実施です。

## 配布上の注意

MacはApple Silicon / macOS 26.5以降向け。Developer ID署名・公証は未対応です。
Windowsはx64の公開プレビューで、コード署名と実機GUIでの確認は未完了です。
GIFはXへ自動添付されません。保存後に手動で添付してください。
v1.0.0は保持し、配布物を差し替えません。

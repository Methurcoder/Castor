# Castor v1.0.0 調整版（管理用バージョン v1.0.1）

Windowsセットアップが起動しない問題と、MacのGIF共有画面がタイトルバーだけになる問題への修正版です。

- SwiftUIのサイズ計測とウインドウのサイズ管理を分離しました。
- 初期表示490×650、最小490×600をウインドウ側で維持し、リサイズに追従します。
- 開き直し時の古い終了通知が新しい画面を消さないようにしました。

## Windowsの修正

- WebView2の画面をCOMのSTAスレッドで開くようにし、セットアップとペット作成画面の起動失敗へ対応しました。
- 同じスレッド上の標準音声処理が失敗しないよう、既存のCOM設定を受け入れます。
- セットアップ画面を開けなかった場合のフォールバックと、起動失敗の診断ログを追加しました。

Windows本体とセットアップを再ビルドしました。Neural TTS補助アプリ、MLモデル、Macセットアップはv1.0.0と同じものを使用します。
Mac本体はGIF修正を含むv1.0.1（build 5）です。

## 確認範囲

Mac本体のReleaseビルド成功。v1.0.1（build 5）、必須4モデル、同梱ライセンス、
ネストしたアプリを含むコード署名の整合性、既知の個人ホームパス検査を確認しました。
署名はad-hocで、Developer ID署名・公証を意味しません。
Windowsの[配布用ビルド38764301838](https://github.com/Methurcoder/Castor/actions/runs/38764301838)が成功しました。
修正コミットcc6973fから本体・セットアップ・必要DLLを生成し、必須4モデル・ONNX Runtime・ライセンスを梱包しています。
MLモデルとONNX Runtimeがv1.0.0配布物と同じであり、Windowsの両実行ファイルが更新されたことを照合しました。
この公開作業では追加テスト、修正後の実機GUIでの導入・GIF作成・保存・X共有は未実施です。
